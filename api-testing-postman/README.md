 # Postman Collections: REST API Testing

Учебные коллекции по тестированию REST API.

## Что внутри
- `api-testing-env.postman-collection.json` — коллекция запросов для тестирования REST API (создана в рамках обучения)
- `api-practice-env.postman-environment.json` — учебное окружение (без реальных токенов)

## Отработанные навыки
- pre-request скрипты
- test-скрипты
- переменные и окружения
- Collection Runner
- Проверка статус-кодов, структуры json, значений полей

## Как запустить
1. Импортировать коллекцию в Postman
2. Импортировать окружение
3. Выбрать окружение в правом верхнем углу
4. Запустить через Collection Runner

## Тестовые данные
Для запуска коллекций используйте тестовые учетные данные:
- Логин: "sinichka"
- Пароль: "qwerty123"

Эти данные представлены в рамках учебного курса и не являются конфиденциальными. Запрос на получение токена- учебный пример. Остальные запросы не требуют авторизации.
